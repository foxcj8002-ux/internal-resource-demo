资源服务使用帮助

本项目提供文件、设备和访问日志等内部资源 API，同时提供浏览器可直接访问的管理页面。

快速开始

1

启动资源服务

启动 Spring Boot 应用后，默认访问地址为 http://localhost:8080/。

2

打开控制台

首页可以查看文件、设备和访问日志，并支持创建基础资源。

3

通过网关访问

当直接访问关闭时，业务 API 必须由 zero-trust-rgw 转发，静态 Web 页面仍可正常打开。

主要 API

方法路径用途
GET / POST/api/files查询或创建文件资源
GET / POST/api/devices查询或创建设备资源
GET/api/access-logs查询访问审计日志
GET/api/system/info查询应用与安全配置
GET/actuator/health查询服务健康状态
